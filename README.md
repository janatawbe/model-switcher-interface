# Model Switcher Interface

A creative AI chat interface built as part of the Numbase Project 1 internship challenge.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Motion
- Node.js
- Express
- OpenRouter

## Architecture

React frontend
↓
Express backend
↓
OpenRouter
↓
Selected AI model
